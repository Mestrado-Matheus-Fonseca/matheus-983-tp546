# Atividade 1 — Estacionamentos inteligentes com RSSF

Relatório acadêmico sobre o uso de uma Rede de Sensores Sem Fio (RSSF/WSN) para detectar vagas livres e informar motoristas por aplicativo.

[Abrir o relatório em PDF](main.pdf)

## Compilação

Com uma distribuição LaTeX e o Make instalados, execute nesta pasta:

```bash
make
```

O arquivo final será `main.pdf`. O diagrama está incorporado no próprio `main.tex`.

> Caso prefira, pode rodar esse comando esse comando na raiz do projeto para conseguir o arquivo final em PDF:
> ```bash
> make -C activities/activitie_1
> ```

## Organização

- `main.tex`: relatório completo, em português;
- `referencias.bib`: referências científicas utilizadas;
- `articles/`: PDFs dos artigos utilizados;
- `materials/`: materiais complementares da atividade.

## Referências científicas

Os artigos utilizados estão listados em `referencias.bib` com DOI. Os PDFs devem ser obtidos em repositórios de editoras ou bibliotecas institucionais, respeitando as respectivas licenças, e armazenados em `articles/`.
